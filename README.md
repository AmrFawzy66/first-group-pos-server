# سيرفر مزامنة First Group POS

سيرفر بسيط (Node.js + Express + MongoDB) وظيفته الوحيدة إنه يخزن بيانات نظام
البيع عندك (منتجات، مبيعات، خزينة، عملاء... كل حاجة) في قاعدة بيانات واحدة
على الإنترنت، بدل ما تفضل محفوظة على جهاز واحد بس. البرنامج نفسه
(first_group_pos.html) **مبني بالفعل** عشان يتكلم مع سيرفر بالشكل ده — مفيش
أي تعديل مطلوب عليه.

بمجرد ما تشغّل السيرفر ده وتحط رابطه في إعدادات البرنامج، أي جهاز (الكمبيوتر
في المحل، موبايلك برا) حاطط نفس الرابط ونفس المفتاح هيشوف **نفس البيانات
لحظة بلحظة**.

---

## الخطوات (من الصفر)

### 1) جهّز قاعدة البيانات على MongoDB Atlas
أنت عامل الكلاستر بالفعل (`amr.6qdxmlu.mongodb.net`). باقي خطوتين:

1. من لوحة Atlas → **Database Access** → تأكد إن المستخدم `mmha43889_db_user`
   عنده صلاحية Read and write، وسجّل الباسورد بتاعه (أو اعمل باسورد جديد من
   "Edit").
2. من **Network Access** → **Add IP Address** → اختار **Allow Access from
   Anywhere (0.0.0.0/0)**. مهم جدًا، لأن السيرفر هيشتغل على Render مش على
   جهازك، والـ IP بتاعه بيتغيّر.

### 2) ارفع الملفات دي على GitHub
اعمل repository جديد (خاص أو عام، مش فارق) وارفعله الملفات التلاتة:
`server.js`, `package.json`, `.gitignore` (متحطش `.env` أبدًا لو عندك واحد).

### 3) استضف السيرفر على Render (مجاني)
1. روح [render.com](https://render.com) واعمل حساب (تقدر تسجل بحساب GitHub
   بتاعك مباشرة).
2. **New** → **Web Service** → اختار الـ repository اللي رفعته.
3. الإعدادات:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. من **Environment** ضيف المتغيرات دي:
   | Key | Value |
   |---|---|
   | `MONGODB_URI` | نفس الكونكشن سترينج بتاعك، بس حط الباسورد الحقيقي بدل `<db_password>` |
   | `API_KEY` | أي كلمة سر طويلة وعشوائية من عندك (مثلاً 30+ حرف/رقم) |
   | `DB_NAME` | `first_group_pos` (أو أي اسم تحبه) |
5. دوس **Create Web Service** واستنى شوية لحد ما يخلص الـ Deploy.
6. هتاخد رابط شبه `https://first-group-pos-server.onrender.com` — ده اللي
   هتحطه في البرنامج.

> ⚠️ **مهم:** متحطش الباسورد أو الـ API_KEY في أي ملف بترفعه على GitHub —
> خليهم بس في خانة Environment على Render.

> ملاحظة: الخطة المجانية على Render بتـ"ينام" السيرفر لو ماحدش استخدمه لفترة،
> وأول طلب بعد النوم بياخد حوالي 30-60 ثانية لحد ما يصحى. طبيعي، مش عطل.

### 4) اربط البرنامج بالسيرفر
افتح `first_group_pos.html` (على أي جهاز — كمبيوتر المحل أو موبايلك) وروح:

**الإعدادات ⚙️ → مكان حفظ البيانات**
- وضع التخزين: **مزامنة مع سيرفر خاص**
- رابط السيرفر الخاص: الرابط اللي اخدته من Render
- مفتاح الوصول (API Key): نفس القيمة اللي حطيتها في `API_KEY`
- دوس **🔌 اختبار الاتصال** — المفروض يقولك "تم الاتصال بالسيرفر بنجاح ✅"
- دوس **💾 حفظ الإعدادات**

كرر نفس الخطوة بالظبط على أي جهاز تاني عايز يشوف نفس البيانات (موبايلك،
تابلت، جهاز تاني في المحل) — **بنفس الرابط ونفس المفتاح**.

من دلوقتي، أي عملية بيع أو تعديل بتتسجل على أي جهاز، هتظهر على باقي
الأجهزة أول ما يفتحوا/يحدّثوا الصفحة.

---

## الروابط (Endpoints) اللي السيرفر بيوفرها
- `GET /kv/:key` — يرجّع قيمة مفتاح معيّن
- `POST /kv/:key` مع `{value}` — يحفظ/يحدّث قيمة مفتاح
- `GET /kv-bulk?keys=a,b,c` — يرجّع كذا مفتاح مرة واحدة (يستخدمها البرنامج
  عند فتح الصفحة عشان يجيب كل البيانات بطلب واحد بدل ما يبعت طلب لكل جزء
  لوحده)
- `POST /kv-bulk` — نفس الفكرة بس للحفظ الجماعي
- كل الروابط دي محمية بهيدر `X-Api-Key` — لازم يطابق `API_KEY`

## تشغيل تجريبي على جهازك (اختياري، قبل الرفع)
```bash
cd server
cp .env.example .env   # ثم عدّل القيم جوه .env
npm install
npm start
```
